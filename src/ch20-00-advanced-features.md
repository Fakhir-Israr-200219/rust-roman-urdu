# Advanced Features

Ab tak, aap Rust programming language ke sab se zyada commonly used parts seekh chuke hain. Ek aur project karne se pehle, Chapter 21 mein, hum language ke kuch aise aspects dekhenge jin se aap kabhi kabhar saamna kar sakte hain lekin shayad har roz use na karein. Jab aapko koi unknown cheez mile to aap is chapter ko reference ke taur par use kar sakte hain. Yahan cover kiye gaye features bohat specific situations mein useful hain. Halaanke aap aksar in ki taraf na jayen, hum yeh ensure karna chahte hain ke aap Rust ke tamam features par achi grasp rakhte hon.

Is chapter mein, hum cover karenge:

* Unsafe Rust: Rust ki kuch guarantees se opt out karne aur un guarantees ko manually uphold karne ki responsibility lene ka tareeqa
* Advanced traits: Associated types, default type parameters, fully qualified syntax, supertraits, aur traits ke hawale se newtype pattern
* Advanced types: Newtype pattern ke bare mein mazeed, type aliases, never type, aur dynamically sized types
* Advanced functions and closures: Function pointers aur closures return karna
* Macros: Compile time par aisa code define karne ke tareeqe jo mazeed code define karta hai

Yeh Rust features ka ek panoply hai jisme har kisi ke liye kuch na kuch hai! Aaiye dive karte hain!

# The Rust Programming Language

*Steve Klabnik, Carol Nichols, aur Chris Krycho ki tasneef, Rust Community ke contributions ke saath*

Is text ka ye version assume karta hai ke aap Rust 1.98.0 (released 2026-08-20) ya uske baad ka version use kar rahe hain, aur tamam projects ki `Cargo.toml` files mein `edition = "2024"` set hai, taake unhein Rust 2024 Edition ke idioms use karne ke liye configure kiya ja sake.

Rust ko install ya update karne ki instructions ke liye [Chapter 1 ke “Installation” section][install]<!-- ignore --> dekhein, aur editions ke baare mein maloomat ke liye [Appendix E][appendix-e]<!-- ignore --> dekhein.

Is kitab ka HTML format online yahan available hai:

https://doc.rust-lang.org/stable/book/

Aur `rustup` ke zariye ki gayi Rust installations ke saath offline bhi available hai. Book kholne ke liye ye command run karein:

```bash
rustup doc --book
```

Community ki taraf se kai [translations] bhi available hain.

Ye text [No Starch Press][nsprust] se paperback aur ebook format mein bhi available hai.

# Object-Oriented Programming Features

<!-- Old headings. Do not remove or links may break. -->

<a id="object-oriented-programming-features-of-rust"></a>

Object-oriented programming (OOP) programs ko model karne ka ek tareeqa hai. Objects ko programmatic concept ke taur par programming language Simula mein 1960s mein introduce kiya gaya tha. Un objects ne Alan Kay ki programming architecture ko influence kiya, jisme objects ek doosre ko messages pass karte hain. Is architecture ko describe karne ke liye, unhon ne 1967 mein *object-oriented programming* ki term coin ki. Bohot si competing definitions yeh describe karti hain ke OOP kya hai, aur in mein se kuch definitions ke mutabiq Rust object oriented hai, jabke doosri definitions ke mutabiq nahi hai. Is chapter mein, hum kuch un characteristics ko explore karenge jinhein aam tor par object oriented samjha jata hai aur dekhenge ke woh characteristics idiomatic Rust mein kis tarah translate hoti hain. Phir hum aapko dikhayenge ke Rust mein ek object-oriented design pattern ko kis tarah implement kiya jata hai aur is ke trade-offs par discussion karenge, is ke muqable mein ke Rust ki kuch strengths ko use karke solution implement karne par kya farq parta hai.

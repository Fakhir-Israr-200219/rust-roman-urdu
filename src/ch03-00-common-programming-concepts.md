# Common Programming Concepts

Ye chapter un concepts ko cover karta hai jo lagbhag har programming language mein nazar aate hain aur ye bhi batata hai ke ye Rust mein kaise kaam karte hain. Bohat si programming languages apni bunyaad mein ek doosre ke saath bohat kuch common rakhti hain. Is chapter mein present kiye gaye concepts mein se koi bhi sirf Rust ke liye unique nahi hai, lekin hum inhein Rust ke context mein discuss karenge aur inhein use karne se related conventions ko explain karenge.

Khaas taur par, aap variables, basic types, functions, comments, aur control flow ke baare mein seekhenge. Ye foundations har Rust program mein mojood hongi, aur inhein shuru mein seekhna aapko ek strong core dega jis se aap agay barh sakte hain.

> #### Keywords
>
> Rust language mein *keywords* ka ek set hai jo sirf language ke use ke liye reserved hai, bilkul doosri languages ki tarah. Yaad rakhein ke aap in words ko variables ya functions ke names ke taur par use nahi kar sakte. Zyada tar keywords ke special meanings hote hain, aur aap apne Rust programs mein mukhtalif tasks perform karne ke liye inhein use karenge; kuch keywords ka filhaal koi functionality associated nahi hai, lekin unhein aisi functionality ke liye reserve kiya gaya hai jo future mein Rust mein add ki ja sakti hai.

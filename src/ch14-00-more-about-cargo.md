# More About Cargo and Crates.io

Ab tak humne apne code ko build, run, aur test karne ke liye Cargo ke sirf sab se basic features use kiye hain, lekin yeh is se kaafi zyada kaam kar sakta hai. Is chapter mein, hum iske kuch doosre, zyada advanced features discuss karenge taake aap seekh sakein ke yeh kaise karna hai:

* Release profiles ke zariye apni build ko customize karna.
* [crates.io](https://crates.io/)<!-- ignore --> par libraries publish karna.
* Workspaces ke zariye large projects ko organize karna.
* [crates.io](https://crates.io/)<!-- ignore --> se binaries install karna.
* Custom commands ke zariye Cargo ko extend karna.

Cargo is chapter mein cover ki gayi functionality se bhi zyada kaam kar sakta hai, is liye iske tamam features ki full explanation ke liye [iski documentation](https://doc.rust-lang.org/cargo/) dekhein.
